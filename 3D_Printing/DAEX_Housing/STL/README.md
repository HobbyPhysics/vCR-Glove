# DAEX Housing STL Files

This directory contains the STL files used to manufacture the three components of the DAEX actuator housing:

- Upper housing
- Lower plate
- Tapper

The STL files were generated from the corresponding OpenSCAD source files in:

`../OpenSCAD_Source/`

## Generating the STL Files

The supplied STL files were generated by opening each printable component in OpenSCAD, performing an **F6 Render**, and then selecting:

**File → Export → Export as STL**

The assembly and dimensions OpenSCAD files are not intended to generate manufacturing STL files.

## Manufacturing

The parts used in the project were manufactured by JLC3DP using:

- **Process:** Multi Jet Fusion (MJF)
- **Material:** Nylon
- **Color:** Black

The STL files can be uploaded to the JLC3DP ordering system for fabrication.

Before ordering, the uploaded models should be inspected in the JLC3DP viewer to confirm the geometry and dimensions.

## Source Files

The OpenSCAD files in `../OpenSCAD_Source/` are the authoritative editable source for these parts.

If a mechanical dimension is changed in the OpenSCAD source, the affected STL file should be rendered and exported again rather than modifying the STL directly.

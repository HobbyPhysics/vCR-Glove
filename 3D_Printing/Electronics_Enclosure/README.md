# Electronics Enclosure

This directory contains the source and fabrication files for the vCR Glove electronics enclosure.

The enclosure houses the printed circuit board, battery, controls, connectors, and related wiring.

## Directory Contents

- `OpenSCAD_Source/` - editable parametric OpenSCAD source files
- `STL/` - rendered STL files for fabrication

See the README files within these directories for additional information.

## Manufacturing

The enclosure parts used in the project were manufactured by JLC3DP using:

- **Process:** SLA
- **Material:** Black resin
- **Supplier:** JLC3DP

The STL files in this repository correspond to the current OpenSCAD source files.

Because SLA dimensions, shrinkage, and warping can vary with resin and process, users employing a different material or manufacturing method should review critical dimensions before fabrication.
